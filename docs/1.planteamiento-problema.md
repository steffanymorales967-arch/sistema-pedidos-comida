# Planteamiento del Problema

Actualmente, los pedidos de comida pueden presentar problemas cuando se realizan de manera manual o mediante procesos poco organizados. Puede existir dificultad para consultar los productos disponibles, registrar correctamente los pedidos, controlar las cantidades y conocer el estado de cada pedido.

Por esta razón, se propone desarrollar un Sistema de Pedidos de Comida en Tiempo Real, que permita gestionar de una manera más organizada el catálogo de productos, el carrito de compras y los pedidos realizados por los usuarios.

El sistema permitirá centralizar la información y facilitar el proceso desde la selección de los productos hasta el registro y seguimiento del pedido.

# Objetivo General

Desarrollar un sistema web para gestionar pedidos de comida, permitiendo a los usuarios consultar productos, agregarlos a un carrito y realizar pedidos, mientras el sistema mantiene la información organizada y actualizada.

# Objetivos Específicos

- Diseñar una base de datos para almacenar usuarios, productos y pedidos.
- Crear un catálogo de productos de comida.
- Permitir la selección de productos mediante un carrito.
- Registrar los pedidos realizados por los usuarios.
- Mostrar el estado de los pedidos.
- Diseñar una interfaz sencilla y fácil de utilizar.
- Preparar el sistema para manejar actualizaciones en tiempo real.
