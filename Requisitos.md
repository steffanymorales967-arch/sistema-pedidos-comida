# Requisitos del Sistema

## Requisitos Funcionales

1. El sistema permitirá el registro e inicio de sesión de los usuarios.
2. El sistema permitirá visualizar un catálogo de comidas disponibles.
3. El sistema mostrará información de cada producto, como nombre, descripción y precio.
4. El usuario podrá agregar y eliminar productos del carrito.
5. El usuario podrá modificar la cantidad de productos del carrito.
6. El usuario podrá realizar pedidos de comida.
7. El usuario podrá consultar el estado de su pedido en tiempo real.
8. El restaurante podrá actualizar el estado de los pedidos.
9. El usuario podrá consultar su historial de pedidos.
10. El administrador podrá administrar productos y pedidos.

## Requisitos No Funcionales

1. El sistema tendrá una interfaz sencilla y fácil de utilizar.
2. El sistema deberá responder rápidamente a las acciones del usuario.
3. La información de los usuarios y pedidos deberá mantenerse segura.
4. El sistema funcionará desde un navegador web.
5. El sistema permitirá actualizar el estado de los pedidos en tiempo real.
