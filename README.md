#  Sistema de Pedidos de Comida en Tiempo Real

## Descripción del proyecto

Este proyecto consiste en desarrollar un sistema web para realizar pedidos de comida en tiempo real. El usuario podrá consultar un catálogo de productos, seleccionar los alimentos que desea, agregarlos al carrito y realizar un pedido.

Además, el sistema permitirá consultar el estado del pedido en tiempo real, desde que es recibido hasta que es entregado.

## Objetivo

Desarrollar un sistema sencillo y fácil de utilizar que permita gestionar pedidos de comida y consultar su estado en tiempo real.

## Funcionalidades principales

* Registro e inicio de sesión de usuarios.
* Visualización del catálogo de comidas.
* Consulta de información y precios de los productos.
* Agregar productos al carrito.
* Modificar cantidades de productos.
* Realizar pedidos.
* Consultar el estado del pedido en tiempo real.
* Administración de productos y pedidos.

## Base de datos

El sistema contará con las siguientes tablas principales:

* Usuarios
* Categorías
* Productos
* Pedidos
* Detalle de pedidos
